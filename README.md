# gala

Android-first mobile app for real-world "side quests" in the Philippines: pick a quest (hike, run, café, class), prove it with an in-app photo checked against GPS, share it to a social feed, and unlock perks from partner businesses.

Status: planning done, app scaffold next (week 0 of `docs/MVP-PLAN.md`).

## Stack
React Native + Expo (TypeScript), Supabase (Postgres + PostGIS, Auth, Storage), kept backend-portable. Why: `docs/decisions/0006-app-framework-and-backend.md`.
